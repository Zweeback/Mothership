Daten & Übergabe

Für diesen MVP ist JSON die transportable Studiowahrheit.

Export / Import

Änderungen werden im Browser gespeichert. Ein JSON-Export ist die einzige dauerhafte, geräteübergreifende Sicherung. Beim Import wird der komplette lokale Datenstand ersetzt.

Ohne Backend kein Team-Sync. Keine automatische Übertragung an andere Chats oder in GitHub Issues. Übergaben können als JSON kopiert werden.

Bitte keine vertraulichen Inhalte in öffentlich zugängliche Repositories übertragen. Im MVP werden diese Daten lokal im Browser aufbewahrt.
